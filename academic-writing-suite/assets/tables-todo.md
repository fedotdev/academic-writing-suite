# Лог таблиц-плейсхолдеров

Этот файл обновляется `draft-agent` автоматически при создании таблицы,
требующей данных, которых нет в переданных источниках. Используется для
отслеживания того, какие таблицы нужно заполнить реальными данными.

## Формат записи

| Раздел | Номер | Описание | Что требуется | Источник данных | Статус |
|---|---|---|---|---|---|
| 2.1 | Таблица 2.1 | Сравнение сценариев | Данные моделирования 3 сценариев | outputs/case-results/ | placeholder |
| 2.3 | Таблица 2.2 | Характеристики оборудования | Паспортные данные 5 устройств | Projects/equipment.csv | prepared |

## Статусы

- **placeholder** — таблица создана, но данные отсутствуют; требуется источник.
- **prepared** — источник данных найден, таблица готова к заполнению.
- **inserted** — таблица заполнена реальными данными и вставлена в текст.

## Правила

1. Таблица с отсутствующими данными **не заполняется правдоподобными строками**.
   Создаётся плейсхолдер в тексте и запись в этом логе.
2. Нумерация N.M — в пределах раздела (номер раздела.порядковый номер таблицы).
3. Подпись НАД таблицей слева: `Таблица N.M — Название` (без точки в конце).
4. В тексте обязательна ссылка: «в таблице 2.1 представлены…».
5. Если все данные для таблицы есть в переданных источниках — draft-agent
   заполняет таблицу сразу, без записи в этот лог.
