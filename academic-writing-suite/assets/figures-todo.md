# Лог рисунков-плейсхолдеров

Этот файл обновляется `draft-agent` автоматически при каждой записи плейсхолдера
рисунка в текст. Используется для отслеживания того, какие рисунки нужно
нарисовать/вставить.

## Формат записи

| Раздел | Номер | Описание | Что нарисовать |
|---|---|---|---|
| 2.1 | Рисунок 2.1 | Схема алгоритма | Блок-схема процесса формализации задачи |
| 2.2 | Рисунок 2.2 | График результатов | Зависимость времени отклика от нагрузки |

## Пример использования

После генерации документа открой этот файл и замени плейсхолдеры на реальные
изображения:

1. Нарисуй/найди изображение согласно колонке «Что нарисовать».
2. Замени строку `![Рисунок 2.1 — ...](E:/akadem-text_agent/academic-writing-suite/references/placeholder.png)` в `outputs/chapters/2.1.md`
   на `![Рисунок 2.1 — ...](images/figure-2.1.png)`.
3. Убедись, что файл `images/figure-2.1.png` существует.
