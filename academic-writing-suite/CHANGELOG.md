# Changelog

Все значимые изменения `academic-writing-suite` фиксируются в этом файле.
Формат соответствует [Keep a Changelog](https://keepachangelog.com/),
версионирование — по [SemVer](https://semver.org/).

## [1.2.0] — 2026-08-15

### Добавлено
- `logic-reviewer-agent` v1.0.0 — логическая проверка подраздела (read-only):
  тезис→доказательство→вывод, разрывы рассуждения, голые утверждения,
  границы применимости, согласованность чисел внутри подраздела.
- `assets/figure-templates.md` — шаблоны рисунков по типу (схема станции,
  структурная схема СЦБ, блок-схема алгоритма, график результатов, таблица
  сравнения сценариев) с обязательным содержанием подписи.
- `assets/tables-todo.md` — лог таблиц-плейсхолдеров (аналог figures-todo.md).
- Eval: 2 golden-кейса для logic-reviewer (case-7 с разрывом логики,
  case-8 чистый) + llm-judge критерий `logic-coherence`.

### Изменено
- Оркестратор: полный конвейер подраздела `draft → logic-reviewer → (доработка
  draft при находках) → humanizer → norm-control`.
- Оркестратор: полный документ — `doc-planner → конвейер по каждому подразделу
  → article-polish` (межразделовая согласованность) → запись в `outputs/`.
- `doc-planner`: создание manifest документа с бюджетом объёма, журналом
  рисунков/таблиц, целевым файлом в `outputs/`.
- `allowed-tools` зафиксированы во фронтматтерах всех 9 агентов.
- Каталог `output/` → `outputs/` унифицирован во всех инструкциях и .gitignore.

## [1.1.0] — 2026-08-15

### Добавлено
- `article-polish-agent` v1.0.0 — межразделовая согласованность после сборки
  главы/ВКР (дубли тезисов, терминологический разнобой, логическая
  последовательность, повторяющиеся зачины подразделов). Read-only.
- `research-agent` v1.1.0 — perspective-guided questioning (4 перспективы:
  метод, граница применимости, результат, позиционирование).
- `calc-agent` v2.1.0 — hybrid EN/RU: процедурные инструкции на английском,
  формулы/ГОСТы/единицы — дословно на русском.

### Изменено
- Оркестратор (SKILL.md): маршрут полного документа без ручной остановки
  «продолжай», запись результатов в `outputs/`, экспорт в DOCX через pandoc.

## [1.0.0] — 2026-08-14

### Добавлено
- Начальный состав suite: `doc-planner`, `research-agent`, `calc-agent`,
  `draft-agent`, `humanizer-agent`, `norm-control-agent`,
  `style-calibrator-agent`.
- Конвейер «один подраздел»: research → calc → draft → humanizer → norm-control.
- Факт-замок, иерархия приоритета правил, протокол делегирования.
- Детерминированные evals: 9 command-чеков + 2 llm-judge, 6 golden cases.
