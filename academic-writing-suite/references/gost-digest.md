# Выжимка ГОСТ 7.32-2017 для агентов

Ключевые правила оформления, необходимые для проверки текста. Полный текст — в `references/GOST_7-32-2017.md`.

## Структура отчёта (раздел 4)

**Обязательные элементы** (выделены полужирным в оригинале):
1. Титульный лист
2. Список исполнителей
3. **Реферат**
4. **Содержание**
5. **Введение**
6. **Основная часть**
7. **Заключение**
8. Список использованных источников
9. Приложения

Для нашего конвейера: содержание и титульник — отдельная задача, фокус на тексте
(введение → основная часть → заключение → список источников).

## Рисунки (6.5)

**6.5.4**: Иллюстрации нумеруются арабскими цифрами. Если рисунок один — «Рисунок 1».

**6.5.6**: Допускается нумеровать иллюстрации **в пределах раздела**:
`Рисунок 2.1` (номер раздела.порядковый номер рисунка).

**6.5.7**: Слово «Рисунок», номер и через тире наименование помещают **в центре ПОД
рисунком без точки в конце**:

```
Рисунок 2.1 — Схема алгоритма формализации
```

**6.5.8**: Наименование с прописной буквы, без точки в конце. Переносы слов не
допускаются.

## Таблицы (6.6)

**6.6.2**: Таблицу располагают непосредственно после текста, в котором она
упоминается впервые. На все таблицы обязательны ссылки.

**6.6.3**: Наименование таблицы — **НАД таблицей слева**:

```
Таблица 2.1 — Сравнение методов
```

Формат: «Таблица Номер — Наименование», с прописной буквы, без точки в конце.

## Формулы (6.8)

**6.8.3**: Формулы располагают по центру строки. Нумерация арабскими цифрами в
круглых скобках в крайнем правом положении. Одна формула — `(1)`.

**Допускается нумерация в пределах раздела**: номер состоит из номера раздела и
порядкового номера формулы, разделённых точкой: `(3.1)`.

**6.8.2**: Пояснения символов — под формулой, в той же последовательности. Первая
строка пояснения начинается со слова **«где»** без двоеточия с абзаца.

## Ссылки (6.9)

**6.9.1**: Ссылки на источники — арабскими цифрами в квадратных скобках в конце
текста ссылки: `[1]`, `[2, 3]`, `[4–6]`.

Порядковый номер ссылки = номер записи в списке использованных источников.

## Список использованных источников (5.10)

**5.10.1**: Список содержит сведения об источниках по ГОСТ 7.0.100-2018 (заменяет
ГОСТ 7.1, 7.80, 7.82).

**5.10.2**: Список включает библиографические записи на документы, использованные
при составлении отчёта. Ссылки в тексте — арабскими цифрами в квадратных скобках.

## Быстрая проверка

Перед сдачей раздела проверь:

- [ ] Рисунки: подпись ПОД рисунком, формат `Рисунок N.M — Название`, без точки
- [ ] Таблицы: надпись НАД таблицей, формат `Таблица N.M — Название`, без точки
- [ ] Формулы: по центру, номер `(N.M)` справа, пояснения «где…» под формулой
- [ ] Ссылки: `[N]` в конце предложения, соответствие списку источников
- [ ] Структура: введение → основная часть → заключение → список источников
