## Обзор

`academic-writing-suite` — это **скилл для AI-агентов** (Claude Code, model service, Cursor и др.), который координирует девять специализированных субагентов для написания разделов ВКР, статей и учебных материалов.

**Ключевые возможности:**

- **Один триггер** — `/academic-writing-suite` маршрутизирует запрос к нужному субагенту
- **Два режима** — написание отдельных разделов или генерация полного документа
- **Конвейер с факт-замком** — `research → calc → draft → logic-reviewer → humanizer → norm-control` с гарантией сохранения чисел, дат, ГОСТов на каждом шаге
- **Идиолект автора** — текст пишется в подтверждённом стиле (правила частотой ≥ 3/7 из `assets/user-idiolect.md`)
- **ГОСТ 7.32-2017** — встроенные правила оформления рисунков, таблиц, формул, ссылок
- **Детерминированные evals** — 9 command-чеков (AI-маркеры, кавычки, плейсхолдеры) + 3 LLM-judge-чека, 8 golden cases

> [!NOTE]
> **Основной продукт — агент** (папка `academic-writing-suite/`). Всё остальное в репозитории — личные рабочие данные автора (калибровка стиля): они исключены из git и не публикуются. Рядовому пользователю они не нужны.

## Быстрый старт

### Требования

- Python 3.11+ (только стандартная библиотека)
- Pandoc (для экспорта в DOCX)
- Один из поддерживаемых AI-инструментов: Claude Code, OpenCode, Cursor, Copilot, Gemini CLI и др.

### Установка

**Через универсальный установщик:**

```bash
./academic-writing-suite/install.sh                # автоопределение платформы
./academic-writing-suite/install.sh --project      # project-level
./academic-writing-suite/install.sh --all          # во все обнаруженные инструменты
```

**Вручную** — скопируйте `academic-writing-suite/` в нужный путь:

| Платформа | Путь |
|-----------|------|
| Claude Code | `~/.claude/skills/academic-writing-suite/` |
| model service | `~/.config/model service/skills/academic-writing-suite/` |
| Cursor | `~/.cursor/rules/academic-writing-suite.mdc` |
| Codex / универсальный | `~/.agents/skills/academic-writing-suite/` |

## Использование

```bash
# Написание раздела
/academic-writing-suite напиши раздел 2.1.1 Постановка задачи формализации

# Полный документ (глава или ВКР целиком)
/academic-writing-suite напиши главу 2
/academic-writing-suite напиши весь диплом

# Проверка и калибровка
/academic-writing-suite проверь текст на AI-маркеры
/academic-writing-suite сравни черновик и мою правку
```

> [!TIP]
> Перед полным развёртыванием прогоните архитектуру на 2–3 реальных разделах ВКР: конвейер увеличивает число вызовов модели на раздел, а рассинхронизация форматов между шагами ломает следующий шаг.

## Архитектура

### Карта субагентов

| Субагент | Роль | Когда вызывать |
|----------|------|----------------|
| **doc-planner** | Планирование структуры документа | «напиши главу N», «напиши диплом» |
| **research-agent** | Сбор фактов, цифр и цитат | «напиши раздел», «собери материал» |
| **calc-agent** | Проверяемые расчёты по нормативам | Параллельно с research, если есть числа |
| **draft-agent** | Черновик по IMRAD + плейсхолдеры рисунков | После research/calc |
| **logic-reviewer-agent** | Логическая проверка подраздела | После draft, до humanizer |
| **humanizer-agent** | Очеловечивание, факт-замок, эм-деши ≤ 3–5% | **Всегда** после draft |
| **norm-control-agent** | Ссылки [N], термины, ГОСТ 7.32 — только помечает | Перед финальным текстом |
| **article-polish-agent** | Межразделовая согласованность | После сборки главы/ВКР (только полный документ) |
| **style-calibrator-agent** | Обучение на правках автора | «сравни черновик и мою правку» |

### Иерархия правил стиля

При конфликте правил применяется этот порядок:

```
1. Факт-замок
   └── Числа, даты, имена, ГОСТы, проценты не искажаются

2. assets/user-idiolect.md (правила с частотой ≥ 3/7)
   └── Подтверждённый идиолект автора

3. Каталог humanizer-agent
   └── 33 академических паттерна + русская механика

4. Общие стилевые правила Projects
   └── Базовые рекомендации
```

> [!IMPORTANT]
> **humanizer-agent — финальная инстанция по стилю.** Его правка не пересматривается norm-control-agent'ом. Иначе конвейер «пинг-понгует» между двумя субагентами на одном абзаце.

## Структура репозитория

```
academic-writing-suite/
├── SKILL.md                 # Оркестратор: маршрутизация, протокол делегирования
├── AGENTS.md                # Краткое описание для агентов
├── install.sh               # Кроссплатформенный установщик (16+ платформ)
├── skills/                  # 9 субагентов
│   ├── doc-planner/         # Планирование структуры
│   ├── research-agent/      # Сбор фактов и цитат
│   ├── calc-agent/          # Проверяемые расчёты
│   ├── draft-agent/         # Черновик + плейсхолдеры рисунков
│   ├── logic-reviewer-agent/  # Логическая проверка подраздела
│   ├── humanizer-agent/     # Очеловечивание текста
│   ├── norm-control-agent/  # ГОСТ 7.32, ссылки, структура
│   ├── article-polish-agent/  # Межразделовая согласованность
│   └── style-calibrator-agent/  # Обучение на правках автора
├── shared/                  # Инструменты субагентов (stdlib, без зависимостей)
│   ├── diff_texts.py        # Дифф по предложениям
│   ├── rhythm_metrics.py    # Эм-деши, ритм, AI-маркеры
│   └── eval_checks.py       # Детерминированные чек-функции
├── assets/                  # Идиолект, фигуры, кандидаты
├── evals/                   # Eval spec + 6 golden cases
├── references/              # ГОСТы, шаблон DOCX, placeholder.png
└── scripts/                 # Обслуживание: run_evals.py, evolve.py
```

## Тестирование

```bash
python3 scripts/run_evals.py --validate        # Проверка спецификации
python3 scripts/run_evals.py                   # Command-чеки по golden-бейзлайну
python3 scripts/run_evals.py --rollout --judge # Judge-чеки с канарейкой
python3 scripts/evolve.py                      # Staleness + evals одним запуском
```

Текущее состояние: **36/36 command-чеков зелёные** (9 чеков × 4 val-кейса).

## Калибровка идиолекта

> [!NOTE]
> Эта функция только для владельца репозитория. Рядовому пользователю достаточно seed-правил из `assets/user-idiolect.md`.

```
draft-agent пишет черновик
         │
         ▼
Автор вручную правит текст
         │
         ▼
/academic-writing-suite сравни черновик и мою правку
         │
         ▼
style-calibrator-agent
  • diff_texts.py → операции (replace/delete/insert)
  • Классификация правок по категориям
  • Порог: ≥ 3 повторений из 7 проверок
         │
         ▼
Правило попадает в assets/user-idiolect.md
         │
         ▼
draft-agent применяет новые правила
```
